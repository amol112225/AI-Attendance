# AttendAI — AI-Powered Attendance Management System

AttendAI is a web application for attendance management featuring AI face recognition and voice verification, built on a modern decoupled architecture:

- **Frontend**: React + Vite + Plain CSS + React Router
- **Backend (Future)**: Python + FastAPI
- **Database & Auth (Future)**: Supabase (Auth, PostgreSQL, Row-Level Security)

---

## Status: Milestone 1 Completed

**Milestone 1: Frontend Foundation and Architecture** has been established in the `frontend/` directory.

### Quick Start (Frontend)

```bash
cd frontend
npm install
npm run build
npm test
npm run dev
```
